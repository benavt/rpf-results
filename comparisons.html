What this release covers

Native ensemble scores use ASDP's midrange inter-proton distances. They are distinct from averages of individual model scores. Visit-weighted summaries count repeat visits. Seeds and reused models do not provide independent experimental validation. Top-DP controls select using the same RPF scores on which they are evaluated.

The 48 state ensembles have exact scored ensemble structures and native residue diagnostics in the structure viewer. Other comparisons expose their saved member lists and single-model structures; their complete scored ensemble files are not included in this web release.
